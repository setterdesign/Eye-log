# Symptom & Eye Log

A personal tracker for symptoms, pain levels and red-eye photos. It installs on a phone as an app and works offline. All data stays on the phone (browser storage). Nothing is sent to a server.

Files: `index.html` (the whole app), `manifest.webmanifest` and `icons/` (install name and icon), `sw.js` (offline cache). No build step: serve the folder from any static host, such as GitHub Pages.

Not medical advice. Bring the trends to your doctor.
